## Microservice project for drawing pixelarts

Services:

1) API gateway
2) Notification
3) Art
4) Auth


Educational project with a microservice architecture that implements a pixel art drawing platform.

## Features

- Microservice communication via gRPC and RabbitMQ
- JWT-based authentication
- Working with jsonb in Postgres
- Storing confirmation codes in Redis
- Sending emails via external SMTP provider
- Saving, editing, and converting pixel art to images
- Integration with S3-like storage (MinIO)
- Containerization with Docker
- Swagger documentation
